# Sushweta Ghosh | Personal Portfolio Website

A clean, modern, and light-themed personal portfolio website designed to showcase my projects, technical skills, and background as a B.Tech Computer Science student.

Live Site: https://sushwetaghosh2007-lgtm.github.io/portfolio/

## Features
- **Monochromatic Light Theme:** White and warm yellow accent palette with clean typography.
- **Fully Responsive:** Scalable layout across mobile, tablet, and desktop devices.
- **Key Sections:** Hero section, About Me, Technical Expertise, Featured Projects, and Contact Details.

## Tech Stack
- HTML5
- CSS3
- FontAwesome Icons
- Google Fonts (Plus Jakarta Sans & Inter)
